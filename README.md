# Chandni Bar — Immersive Website

A React + Vite single-screen cinematic experience based on the Chandni Bar BRD and technical specification.

## Run

```bash
npm install
npm run dev
```

Then open the Vite local URL.

## Build

```bash
npm run build
npm run preview
```

## Included

- Full-screen exterior → interior transition
- Chandni Bar title treatment
- Local device clock
- Atmospheric status indicator
- ENTER BAR activation flow
- Custom music player UI with play/pause/previous/next/seek
- Original demo WAV used as a temporary audio source
- Responsive desktop/tablet/mobile/landscape compositions
- Subtle fan, haze, lighting, grain and vignette effects
- Reduced-motion accessibility handling

## Production asset note

The supplied BRD reference images are used as the initial visual assets. Replace them in `public/assets/` with production-approved assets when available.

The included `public/audio/chandni-midnight.wav` is an original demo ambience created for prototyping. Replace it with properly licensed production music before public deployment.
